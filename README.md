## 📌 Descripción del Proyecto
Simulador interactivo del modelo de una Máquina Tragamonedas (Slot Machine) reutilizando el paquete gráfico `shapes` en BlueJ.

## ⚙️ Estructura del Modelo
- `SlotMachine`: Clase principal que controla el juego, las ruedas y los premios.
- `Wheel`: Modela cada rueda individual con sus símbolos (colores CSS) y rotación circular.
- Paquete `shapes`: `Canvas`, `Rectangle`, `Circle`, `Triangle` para la representación visual.
